Behind the projects

Where the projects come from

Hiren's own notebook

Hiren types each project into his own control panel once. The website reads from it and shows the projects. Change the notebook, and the site changes too, with no new code.

Programmers' name: VAMS, a content system (CMS) Hiren built himself.

A photocopy, just in case

If the notebook is asleep, say while Hiren is updating it, the site keeps a photocopy of the last version. So visitors still see the projects. It never shows a blank page.

Programmers' name: a snapshot fallback.

The site copies its content from Hiren's own mini control panel, and keeps a backup copy for when the panel is busy. Ask Nami: why keep a photocopy instead of just asking the notebook every single time?
