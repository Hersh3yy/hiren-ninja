A clever trick

Reading your whole playlist

The locked door

Spotify's main desk hands over only the first 100 songs of a shared playlist, then says "come back in 20 hours." No good if your playlist has 900 songs.

The side door

So the planner knocks on the same door Spotify's own web player uses, and reads the rest from there, up to 1,000 songs.

The honest part: this is not the "official" way. If Spotify ever shuts that side door, the planner falls back to the first 100 songs and tells you right on the screen that it only got part of your list.

This is a real trade-off: a trick that gets the whole playlist, but could stop working if Spotify changes things, so the app admits when it only got part. Ask Nami: is it fair to use the side door the web player uses? Why or why not?
